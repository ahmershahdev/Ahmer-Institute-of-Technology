# Admin guide

Sign in at `/admin/login.php`. Super admins also enter the security key.

## Applications
Open **Applications**, choose **Review**, check each document (View / Download), add a note, and **Approve** or **Reject**. Approval shows the new student ID and a one-time temporary password: share it privately. The student is enrolled in first-semester subjects automatically.

## Sub-admins
**Manage Sub-Admins** creates accounts with any of nine permissions (admissions, students, teachers, staff, departments, timetable, content, reports, sub-admins) and an optional expiry.

## Teachers and staff
- **Manage Teachers**: create (a temporary password is shown once), edit, reset password, disable, and **Save subjects** to assign what they teach.
- **Manage Staff**: role HOD links the person to their department.

## Semester controls
Pick a student and semester to enable fee and exam challans, set attendance overrides, and release exam slips. Uploaded receipts and attendance appeals appear below for review.

## Timetable
Slots cannot overlap for the same teacher or room; the form explains any clash.
